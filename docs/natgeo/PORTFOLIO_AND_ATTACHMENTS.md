# NatGeo portfolio and attachments plan

## Goal

The portfolio must prove one thing:

> **The applicant can already tell human stories visually and in long form.**

It should not look like a travel-photo dump.

## Portfolio structure

Target: a small, edited body of strongest work.

### Sequence A — People and lived culture

Select images that show:

- individuals;
- relationships;
- work;
- ritual;
- learning;
- ordinary life;
- emotion;
- context.

Avoid overloading the portfolio with architecture, sunsets, monuments, or scenic travel images.

### Sequence B — Buddhist / Southeast Asian context

Include the strongest available work demonstrating:

- familiarity with Buddhist environments;
- visual restraint;
- access beyond tourist viewpoints;
- people rather than only sacred objects.

### Sequence C — Visual range

A few images showing:

- night/low light;
- environmental portrait;
- event/ritual;
- landscape used contextually;
- documentary sequence.

## Caption standard

Each image should have:

- location;
- year;
- one-sentence context;
- what is happening;
- no invented interpretation.

## Writing sample

Prepare one concise English sample demonstrating:

- narrative voice;
- cultural context;
- clarity without academic jargon;
- ability to move between scene and idea.

Preferred source: an original essay or adapted published writing that is fully owned by the applicant.

## Video

If a video sample is required or useful:

- 60–120 seconds;
- observational rather than promotional;
- human voices;
- restrained music;
- no startup-style animated pitch.

## Applicant bio

Prepare:

- 50-word bio;
- 100-word bio;
- 250-word bio.

All versions should foreground:

1. storyteller/photographer;
2. education and Southeast Asia;
3. Buddhist lived experience;
4. writing;
5. technology only insofar as it supports execution.

## Useful links

- Lotos Star GitHub repository
- photography portfolio / Instagram
- published books or author page
- relevant educational/project links

## Do not submit

- full corporate CV unless requested;
- 40 unrelated project links;
- generic certificates;
- weak travel images simply because the country is exotic;
- confidential documents;
- claims that cannot be verified.

## Missing asset work

Before final submission, create:

1. final 15–25 image portfolio;
2. English captions;
3. 100-word applicant bio;
4. 250-word applicant bio;
5. one writing sample;
6. one short visual reel if useful;
7. concise CV tailored to storytelling/cultural work.
