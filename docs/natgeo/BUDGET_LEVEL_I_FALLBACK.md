# Budget draft — Level I fallback

**USD 20,000**

Use this only if the live Funding Portal restricts the applicant to Level I or if a narrower first-stage project is strategically preferable.

## Scope change

The USD 20k version is **not** the USD 100k project compressed unrealistically.

It becomes a Thailand-centered documentary pilot.

Primary field:

- Thailand;
- Myanmar-connected Buddhist communities in Thailand;
- no dependence on direct Myanmar travel.

Primary outputs:

- photographic essay;
- oral histories;
- short documentary;
- written narrative;
- prototype immersive sequence rather than full fulldome production.
